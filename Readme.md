# Project Eben

Project Eben is a project to make a portable Raspberry Pi that strays from the typical tablet-style designs. 

> [!CAUTION]
> This software is under development and currently should not be used in production as of right now.

> [!IMPORTANT]
> No installers for system components are currently provided. Proceed at your own risk!

## Eben 

Project Eben is meant to be an extension to another PC, especially one you do not fully control (school, no admin, locked down OS, etc), with the ability to plug in your own I/O if you choose to do so.

Project Eben's main goal is to turn any computer that has either: 
* A modern web browser
    * Blink 92 or higher 
        * Chrome 92+
        * Edge (Chromium) 92+
        * Opera 78+ 
        * Brave 1.28+
        * Electron 14+ 
        * MS Edge WebView2 (92+)
    * Gecko 92 or higher 
        * Firefox 92+, Firefox ESR 91+
    * WebKit 15 or higher (Apple platforms)
        * Safari 15+
    * WebKitGTK 2.34 or higher
        * GNOME Web (Epiphany) 41+
* A VNC client of it's own, or
* A SSH client

into a powerful cyberdeck.

## Stockwood
Stockwood is another take on the Project Eben idea. While it still can be used as Eben as it still runs Ironmouse and Ranboo, it also includes it's own screen and battery and is meant to be used as it's own self contained system.
