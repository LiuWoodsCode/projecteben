# Focuses and values of the project

## Cyberpunk
Project Eben itself follows the cyberpunk formula very well in my eyes, just being able to bring a small SBC with you to turn any computer into a personal linux machine fits the description well. 

As part of this cyberdeck focus, cyberpunk ideals and style should be used for the whole project.

## Privacy
Privacy is one of our priorities with Project Eben. You should be able to turn on the device without worrying that we might be selling it to Palantir or something.
